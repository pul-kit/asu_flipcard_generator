**Flipcard Generator**
To design flipcards that are styled differently, use Articulate Storyline!

**HOW TO GENERATE FLIPCARDS:**
 1. Go to GitHub [https://github.com/pul-kit/asu_flipcard_generator/blob/main/flipcard_generator.html] and download the flipcard_generator HTML file.
 2. RED BOX 1: Upload an image for the landing page of the flipcard.
     - Uploading an image for the landing page also allows you to edit the two sentences on the landing page.
     - If you don't upload an image, the flipcard will generate without a landing page.
 3.  Uplaod a background image if you'd like.
 4.  Choose the theme of the flipcard. You can also choose a custom theme.
 5.  Choose how many flipcards you want the interactive to have. If you choose 5 or 7 flipcards, you will also have the option to make all flipcards the same size.
 6.  Checking the Font Size box keeps font size the same across the front and across the back of the cards. If unchecked, the text inside the flipcards will fill the card.
 7.  For each flipcard, you will see a front field and a back field. Fill those out.
 8.  Click the "Generate HTML" button. Once you click, the "Download HTML" button should appear.
 9.  Click the "Download HTML" button to download your flipcard.
 10. If everything looks good, upload to cloud and embed!
